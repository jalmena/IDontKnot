# Rope textures

`rope-laid-color.jpg`, `rope-laid-normal.jpg` and `rope-laid-roughness.jpg` are derived from **Rope001** by ambientCG (<https://ambientcg.com/a/Rope001>), released under the Creative Commons CC0 1.0 Universal licence.

Changes: the 1K JPG maps were recompressed, and the colour map was converted to grey and brightened so that each rope style can give it its own colour.
